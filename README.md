# 🐷 КОПИЛКА

Консольное приложение для управления накоплениями.

## Возможности

- Добавление целей (название, сумма, категория)
- Пополнение и снятие средств
- Отслеживание прогресса
- Категоризация целей
- Удаление целей

## Запуск

```bash
python3 main.py
## Технологии
